Support

Found a bug, got a question or an idea? Contact us on GitHub

You'll need a free GitHub account to post. Please include your iPhone model, iOS version and the game version (Menu → About).

Common questions

Where are my saved games?
On your iPhone only. The game saves automatically every week; Menu → Saved games lets you load or delete them. Deleting the app deletes your saves.

How do I start again?
Menu → New game. Your current game stays saved.

What is sandbox mode?
A relaxed mode where you can't be sacked and the club can't go bust. Choose it when you start a new game.

Can I use real club names?
Yes, with a data pack. See Data packs.

I bought in-game money but didn't receive it.
Make sure you're online and reopen the game: purchases that didn't finish are delivered when it starts. If it still hasn't arrived, contact us, or ask Apple for a refund at reportaproblem.apple.com.

I've been sacked. Is my game over?
Yes, that save is finished, but you can start a new game from the menu at any time.
